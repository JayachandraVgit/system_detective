## Objective

Complete Checkpoint 1 by capturing labelled screenshots of the five required Linux system inspection commands.

## Work Completed

- `lscpu` — CPU and architecture information
- `free -h` — memory and swap information
- `top -b -n 1` — system and process activity
- `ps -eLf` — process and thread information
- `strace -c ls` — system-call summary

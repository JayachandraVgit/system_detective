# System Detective — CIE-1

Computer Organisation & Operating Systems (CO1)

## Objective

Inspect and analyze a Linux environment using system-level commands,
investigate memory locality using row-major and column-major traversal,
and present the findings through a simple dashboard.

## Environment

- Ubuntu 24.04.2 LTS
- WSL2
- x86_64
